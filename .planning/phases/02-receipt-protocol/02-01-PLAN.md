<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Raw parameter bytes to strict JSON tokens | Untrusted caller bytes enter protocol parsing. |
| Parsed JSON to RFC 8785 bytes | One interpretation must survive validation and canonicalization. |
| Receipt values to semantic validation | Caller-owned strings and slices cross into protocol state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01 | Tampering | `DigestParams` | mitigate | Use strict stdlib validation before `jcs.Transform`. Reject duplicates, invalid Unicode, trailing values, and semantic ambiguity. |
| T-03 | Information Disclosure | Receipt and parser errors | mitigate | Store digests only. Use closed errors and scan sentinels across state, bytes, and errors. |
| T-05 | Denial of Service | JSON token and canonicalization path | mitigate | Reject depth above 32 and canonical output above 1 MiB. Fuzz parser boundaries in 02-02. |
</threat_model>
